Release notes for Rewordly

Version 1.4.0

Changes in 1.4.0

  • Keyboard shortcuts: Rewrite with Ctrl+Shift+E and check grammar with Ctrl+Shift+L. The popup shows your shortcuts and a link to Chrome’s shortcut settings.
  • On update, the extension opens Chrome’s shortcuts page once so you can assign or confirm the default shortcuts.
  • Uninstall feedback: When you remove the extension, Chrome can open an optional feedback form so we can learn how to improve.
  • Context menu (Rewrite / Check grammar) now works correctly even when “Show hover buttons” is off for the current page.

Changes in 1.3.0

  • Account & login: Sign in via the website for more daily usage. Session is managed in the extension popup.
  • Supabase authentication: Secure login integrated; API requests use your session for usage tracking.
  • Free limits by email: When you hit limits, use "Email for free limits" to request more—or email us directly. Payment plans coming soon.
  • Popup UI: Account section in English; "Sign out" and clearer messaging. Upgrade button replaced with "Payment plans coming soon" and email link for free limits.
