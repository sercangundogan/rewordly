How to Test the Extension

  1. Make sure the Rewordly extension is installed and enabled
  2. Configure your OpenAI API key in the extension settings
  3. Select any text below to see the floating "Rewrite" button
  4. Click the button to rewrite the selected text
Note: You need a valid OpenAI API key to use this extension. Get one from OpenAI Platform.
